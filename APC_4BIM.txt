APC-03
Considere o código:

    opcao = input('Continuar? (s/n): ')

    while opcao != 's' or opcao != 'n':
        print('Opcao invalida!')
        opcao = input('Continuar? (s/n): ')

    print('Opcao aceita:', opcao)

O que acontece se o usuário digitar s?
A) Imprime 'Opcao aceita: s', pois s é uma das opções esperadas
B) Imprime 'Opcao invalida!' uma única vez e depois aceita o s
C) Dá erro, pois or não pode ser usado em condição de while
D) O programa termina sem imprimir nada
E) Imprime 'Opcao invalida!' e volta a perguntar sem parar, pois a
   condição é verdadeira para qualquer valor digitado


APC-04
Qual é a ordem dos valores impressos?

    def preparar():
        print("1")
        servir()
        print("2")

    def servir():
        print("3")

    print("4")
    preparar()

A) 1 / 3 / 2 / 4
B) 4 / 1 / 3 / 2
C) 4 / 1 / 2 / 3
D) 1 / 2 / 3 / 4
E) Erro, pois servir() é usada antes de ser definida


APC-05
Qual é a saída do código?

    def tem_negativo(lista):
        for n in lista:
            if n < 0:
                return True
            else:
                return False

    print(tem_negativo([5, -2, 8]))

A) True
B) None
C) -2
D) False
E) Erro, pois uma função não pode ter dois return

    contador = 0

        contador += 1

B) 0
C) 1
D) UnboundLocalError
E) None

    def adicionar(lista):

    numeros = [1, 2, 3]
    adicionar(numeros)

B) None, pois a função não tem return
C) Erro, pois lista não existe fora da função
D) 1
E) 4, pois append altera a própria lista recebida
