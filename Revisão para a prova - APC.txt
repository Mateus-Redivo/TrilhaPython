RESUMO

parâmetro = nome na definição; argumento = valor na chamada
print MOSTRA; return DEVOLVE (e encerra a função)
sem return, a função devolve None
atribuir dentro da função cria uma variável local
try: o erro abandona o resto; else: se NÃO deu erro; finally: sempre
except TipoDoErro: só pega esse tipo; outro derruba o programa
string não muda no lugar; função que filtra devolve lista nova
