# 1º Ano: Sistemas em Python (Temas dos Grupos)

Cada grupo constrói um sistema de linha de comando (menu no console) em Python para organizar
informações do dia a dia, seguindo o mesmo padrão do sistema de controle de produtos usado como
referência: um menu numerado e cada opção fazendo uma coisa só.

Para guardar os dados, cada grupo pode escolher entre vetores (listas paralelas, uma lista por
campo) ou matriz (uma lista só, com um registro completo em cada posição): os dois jeitos são
aceitos, e cada tema explica as duas opções.

Todos os temas pedem a mesma espinha dorsal (cadastrar, listar, atualizar, uma ação especial de
status, remover e um relatório), mudando apenas o que está sendo controlado. Isso é proposital:
o objetivo não é decorar um problema específico, mas praticar a mesma lógica de CRUD o suficiente
para ela ficar natural.
